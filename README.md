# us-stock-agent — ทีมเอเจนต์ลงทุนหุ้นสหรัฐ (forward test)

เว็บ: https://us-stock-agent.tevez7549.workers.dev

Cloudflare Worker + D1 (`us-stock-agent`) · push ขึ้น `main` แล้ว Cloudflare deploy ให้อัตโนมัติ
เอเจนต์ Python รันบน GitHub Actions ตามเวลา ไม่ต้องเปิดคอม

## ใช้ทำอะไร

- **ภาพรวม** มูลค่าพอร์ตจำลอง (ดอลลาร์/บาท) เทียบการถือ SPY เฉยๆ ราคาสดตอนตลาดสหรัฐเปิด Kill switch
- **ตัดสินใจ** แพ็กเกจรายสัปดาห์: สรุปภาษาไทย ออเดอร์พร้อมเหตุผล อนุมัติ/ปฏิเสธทีละรายการ ใบสั่งสำหรับกดใน Dime
- **Backtest** ผลย้อนหลังเทียบ SPY แยกรายปี ช่วงแรก/ช่วงหลัง และการทดสอบความทนทาน
- **Journal** บันทึกทุกการตัดสินใจของเอเจนต์และของคุณ
- **ตั้งค่า** Finnhub key (ราคาสด) และเปลี่ยนรหัสผ่าน

## รอบการทำงาน (GitHub Actions)

| เวลา (ไทย) | ทำอะไร |
|---|---|
| อังคาร–เสาร์ 06:30 | ดึงราคาปิด เทรดออเดอร์ที่อนุมัติแล้ว บันทึกมูลค่าพอร์ต |
| เสาร์ 09:00 | สร้างแพ็กเกจตัดสินใจ + อัปเดต backtest |

สั่งรันเองได้ที่แท็บ Actions → agents → Run workflow

## โครงสร้าง

- `public/index.html` หน้าเว็บ · `src/worker.js` API + ล็อกอิน + ราคาสด · `schema.sql` ตาราง D1
- `orchestrator.py` ผู้จัดการ · `agents/` เอเจนต์แต่ละตัว · `config.py` กลยุทธ์ + ลิมิตความเสี่ยง (แก้ที่นี่ที่เดียว)
- `paper.py` ฐานข้อมูลพอร์ต (บนคลาวด์ = D1 ผ่าน Worker, บนคอม = SQLite)
- `backup.py` / `backup.bat` สำรองข้อมูลจาก D1 ลงคอม (`data/backup/`)
- `server.py` / `start.bat` เวอร์ชันทดลองบนคอม (มีปุ่มจำลองย้อนหลัง 1 ปี และ backtest ปรับค่าได้)
- `tests/test_system.py` ทดสอบความถูกต้อง

## ความปลอดภัย

- เว็บต้องล็อกอิน · ทำได้แค่อ่าน อนุมัติ/ปฏิเสธ Kill switch และตั้งค่า แก้พอร์ตหรือลิมิตไม่ได้
- เอเจนต์บน GitHub ยืนยันตัวด้วย OIDC ของ GitHub (Worker ตรวจว่ามาจาก repo นี้ สาขา main) ไม่มี secret ใน repo
- คอมใช้ `AGENT_TOKEN` ในไฟล์ `.env` (ไม่อัปขึ้น GitHub) · Worker เก็บแค่ค่า hash
- บนคลาวด์ใช้ข้อมูลจริงเท่านั้น ดึงราคาไม่ได้ = หยุดรอบนั้น

## กลยุทธ์ตั้งต้น (ยังไม่ผ่านการพิสูจน์ ดูแท็บ Backtest ก่อน)

ทุกวันศุกร์เลือก 6 ตัวที่โมเมนตัม 6+12 เดือนสูงสุดและอยู่เหนือเส้น 200 วัน ถ่วงตามความผันผวน · S&P500 ต่ำกว่าเส้น 200 วัน → ถือของเสี่ยง 30% ที่เหลือพันธบัตร/ทอง/SHY · ลิมิต หุ้น ≤15% ETF ≤25% กลุ่ม ≤40% เงินสด ≥5% · พอร์ตลง 15% → ลดของเสี่ยงครึ่งหนึ่ง · ค่าธรรมเนียมใน `config.py` เป็นค่าสมมติ
